# تلا — النسخة الثابتة (GitHub Pages)

هذه ملفات الموقع الجاهزة للنشر على GitHub Pages — انسخها **كما هي وبنفس بنية المجلدات** إلى جذر الـ repository.

## خطوات النشر (دقيقتان)

1. ارفع كل الملفات الموجودة هنا إلى **جذر** الـ repository (مع الحفاظ على مجلد `_next` كما هو).
2. **مهم:** تأكد أن ملف `.nojekyll` موجود في جذر الـ repo (مضمّن هنا — لو مش ظاهر بسبب الإخفاء أنشئ ملفاً فارغاً بهذا الاسم).
3. من إعدادات الـ repo: **Settings ← Pages ← Source: Deploy from a branch ← main ← /(root) ← Save**.
4. بعد دقيقة: الموقع يعمل على `https://<اسم-حسابك>.github.io/<اسم-المستودع>/`

> المسار المبني هنا باسم `/tala-logistics` — لو اسم المستودع مختلف، أعد البناء من الكود المصدر بالأمر: `bun run build:static /اسم-المستودع`

## تسجيل الدخول

- النظام يفتح مباشرة بحساب **مدير النظام** بدون شاشة دخول.
- كلمة المرور الافتراضية `123456` — غيّرها من الإعدادات ← الأمان.

## البيانات

- كل البيانات تُخزَّن داخل متصفح الجهاز (IndexedDB) — لا تُرسل لأي مكان.
- **نسخة احتياطية دورية**: الإعدادات ← النسخ الاحتياطي ← تنزيل نسخة.
- لنقل البيانات لجهاز آخر: استعادة من ملف على الجهاز الجديد.
