========================================================
 طريقة رفع نسخة تلا الثابتة (HTML) على GitHub Pages
========================================================

الملف المطلوب رفعه ملف واحد فقط: index.html
النسخة دي بتشتغل مباشرة على GitHub Pages من غير سيرفر
وكل البيانات بتتحفظ داخل متصفح الجهاز نفسه.

--------------------------------------------------------
الطريقة الأسهل (من الكمبيوتر — GitHub Desktop):
--------------------------------------------------------
1) افتح GitHub Desktop واعمل Clone لمستودع tala-logistics
2) امسح كل الملفات القديمة اللي جوه المجلد (مادام مش محتاجها)
   وسيب بس ملف .gitignore لو موجود (وممكن تشيله برضه)
3) انسخ ملف index.html الجديد جوه المجلد (في الجذر — مش جوه فولدر)
4) اكتب وصف الحفظ مثلاً: "النسخة الثابتة — HTML"
5) اضغط Commit to main ثم Push origin
6) استنى دقيقة أو اتنين وافتح:
   https://ziaddd12.github.io/tala-logistics/

--------------------------------------------------------
من الموبايل أو من غير برامج (موقع GitHub نفسه):
--------------------------------------------------------
1) افتح github.com/ziaddd12/tala-logistics
2) اضغط Add file ثم Upload files
3) اسحب ملف index.html واعمل Commit
   (لو فيه ملفات قديمة كتير، امسحها الأول واحدة واحدة:
    افتح الملف ← ايقونة الثلاث نقط ← Delete file ← Commit)
4) استنى دقيقة وافتح الموقع

--------------------------------------------------------
لو النسخة القديمة ظهرت مخزنة (Cache):
--------------------------------------------------------
- اعمل تحديث للصفحة بإصبعين (Hard refresh) أو
- افتح الرابط بنافذة تصفح خفي / امسح كاش المتصفح

--------------------------------------------------------
لو بتستخدم أوامر git:
--------------------------------------------------------
git clone https://github.com/ziaddd12/tala-logistics.git
cd tala-logistics
# امسح محتويات المجلد القديمة ثم انسخ index.html هنا
git add -A
git commit -m "النسخة الثابتة — HTML"
git push
